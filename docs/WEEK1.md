# 1주차: Unity 복습

목표는 "3D 공간에서 캐릭터를 움직이고, 적에게 데미지를 주는 것"을 직접 만들어 보는 것입니다. 여기서 만든 코드는 2주차 프로토타입의 바탕이 됩니다. 각 과제는 개인 Sandbox 씬에서 합니다.

| 일차 | 과제 | 익힐 개념 |
| --- | --- | --- |
| 1 | 환경 세팅 ([SETUP.md](SETUP.md)) 끝내기, 첫 PR 머지 | Unity Hub, Git LFS, PR |
| 2 | 바닥(Plane)과 캡슐 캐릭터 배치, WASD로 이동 | GameObject, Transform, `Update`, `Time.deltaTime` |
| 3 | 탑다운 카메라가 캐릭터를 따라오게 하기, 마우스 방향 바라보기 | Camera, `LateUpdate`, Raycast |
| 4 | 새 Input System으로 이동 입력 바꾸기, 2P용 두 번째 입력(방향키) 추가 | Input System, Action Map |
| 5 | 적(빨간 큐브)이 플레이어를 따라오게 하기 | NavMesh, NavMeshAgent |
| 6 | 클릭으로 투사체 발사, 적 체력 감소, 0이면 제거 | Prefab, `Instantiate`, Collider/Trigger, `IDamageable` 인터페이스 |
| 7 | 이번 주 회고 작성 (한 것 / 막힌 것 / 배운 것) | |

## 진행 방식

- 하루 과제를 시작할 때 "N일차 시작"이라고 말해 주시면, 그날 필요한 개념 설명과 단계별 코드를 같이 짭니다.
- 코드를 처음부터 받아 적기보다, 설명을 듣고 직접 쳐 본 뒤 리뷰를 받는 쪽이 복습에 훨씬 좋습니다.
- 에러가 나면 Console 창의 빨간 메시지를 그대로 복사해서 보내 주세요.

## 조교님 1주차

- 게임 규칙 초안: 승리/패배 조건, 한 판 길이, 캐릭터 2종의 역할
- 캐릭터별 기본공격 + 스킬 2개 아이디어 (수치는 대략적으로)
- 적 3종 + 보스 아이디어
